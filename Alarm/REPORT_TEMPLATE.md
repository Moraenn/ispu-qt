# Отчет по лабораторной работе

## Задание
Разработать приложение «Будильник», позволяющее отображать текущее время, задавать время срабатывания и включать или выключать будильник. Для построения интерфейса использовать менеджеры компоновок, для взаимодействия элементов интерфейса использовать сигнально-слотовый механизм Qt.


Добавьте в отчет:

1. Окно приложения в обычном режиме.
2. Окно приложения с установленным временем будильника.
3. Окно приложения в момент срабатывания сигнала.
4. Скриншот запуска под Windows.
5. Скриншот запуска под Ubuntu Linux.

## Выводы по работе
В ходе выполнения работы было разработано приложение «Будильник» на Qt Widgets. В приложении реализовано отображение текущего времени, установка времени срабатывания будильника, включение и выключение сигнала, а также визуальное уведомление о срабатывании. При создании интерфейса использованы менеджеры компоновок, а взаимодействие между элементами выполнено с помощью сигнально-слотового механизма Qt.
